Accessibility Statement

Our commitment to making Hubro accessible to everyone

Last updated: 1 June 2025
✓ Actively improving accessibility

Our commitment

Hubro is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying relevant accessibility standards.

We believe that international residents in Ireland deserve a platform that is usable by everyone, regardless of ability or disability.

Conformance status

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities.

Hubro is currently partially conformant with WCAG 2.1 Level AA. We are actively working to address remaining accessibility issues.

Accessibility features

Currently implemented:

  • Semantic HTML structure with proper heading hierarchy
  • High colour contrast ratios throughout the platform
  • Responsive design that works on all screen sizes
  • Keyboard navigation support for main actions
  • Alt text on informational images
  • Language selector for 9 languages
  • Clear focus indicators on interactive elements
  • Form labels associated with their inputs
  • Error messages that describe what went wrong

In progress:

  • Full screen reader compatibility
  • ARIA labels on complex interactive components
  • Skip navigation links
  • Enhanced keyboard navigation for modals

Known limitations

We are aware of the following accessibility limitations and are working to address them:

  • Some complex interactive components (job search filters, property search) may not be fully accessible to screen reader users — we are working on ARIA improvements
  • Some PDF documents may not be fully accessible — we are working on accessible alternatives
  • Some older content may not meet all accessibility standards

Technical specifications

Hubro relies on the following technologies for conformance:

  • HTML5
  • CSS3
  • JavaScript

The platform has been tested with the following tools and browsers:

  • Chrome (desktop and mobile)
  • Safari (iOS)
  • Firefox
  • Microsoft Edge
